# 3D-модель квартиры

Интерактивная 3D-модель квартиры с реальными размерами: 3D-вид, план, прогулка, расстановка мебели и предметов на стенах, свет, шторы, двери, варианты обстановки. Можно загрузить свою планировку и замеры.

Открыть: https://orangeonsugar.github.io/kvartira-3d/

## Своя планировка

Вкладка «Квартира» → «Планировка» → «Загрузить свою».

1. **Подложка (необязательно).** Загрузите фото или PDF плана и задайте масштаб: отметьте две точки и впишите расстояние между ними в миллиметрах.
2. **Комнаты.** Растяните прямоугольник по внутренним стенам. Г-образная комната собирается из нескольких частей. Края прилипают к соседним комнатам с зазором на перегородку.
3. **Замеры.** Выберите комнату и впишите ширину, глубину и, если есть, площадь по замеру. Редактор сравнит её с нарисованной и предупредит о расхождении.
4. **Двери и окна.** Выберите инструмент и нажмите на стену. Ширина, отступ от угла, подоконник и сторона открывания задаются в панели.
5. **«Построить 3D».** Планировка сохраняется в браузере, мебель для неё хранится отдельно.

План можно скачать файлом и открыть на другом устройстве.

### Автоматическое распознавание

Загрузите план, впишите площадь квартиры без балкона и нажмите «Распознать стены, окна и двери». Файл никуда не отправляется: всё считается в браузере. Площадь нужна для масштаба, обычно это средняя из цифр на плане.

Распознавание находит стены, комнаты, двери по нарисованному полотну, окна и балкон, определяет тип пола и кладёт результат поверх подложки. Это черновик, его нужно сверить с планом:

- **Подписи не читаются.** Имена «Кухня», «Санузел», «Кладовая» определяются по размеру и обстановке, поэтому могут оказаться не на своих комнатах.
- **Санузлы получаются меньше настоящих.** Сантехника и шкафы на плане похожи на стены.
- **Комнаты собираются из прямоугольников.** Скосы и дуги становятся прямыми.
- **Подходят чертежи со стенами в две линии или жирной линией и с нарисованными полотнами дверей.** Другие стили, фото под углом и рукописные планы могут распознаться хуже. Пометки поверх чертежа тоже мешают.

Исправить можно всё: выберите комнату и поменяйте название или пол, потяните края, объедините с соседней или удалите. Лишний проём удаляется, недостающий ставится инструментом. Если знаете точную площадь одной комнаты, план подгонится под неё целиком.

## Формат файла

```json
{
  "format": "flat3d-plan",
  "version": 1,
  "name": "Студия",
  "ceiling": 2.7,
  "wall": 0.2,
  "rooms": [
    { "id": "r1", "name": "Комната", "floor": "wood", "area": 30.0, "rects": [[0, 0, 6, 5]] }
  ],
  "openings": [
    { "type": "window", "axis": "x", "line": 0, "from": 2, "to": 4, "sill": 0.9 },
    { "type": "entrance", "axis": "x", "line": 5, "from": 1, "to": 1.9, "side": -1, "room": "r1" }
  ]
}
```

Все размеры в метрах. X направлена вправо, Z вниз.

- `rects`: части помещения по внутренним стенам, `[x0, z0, x1, z1]`. Необязательные `area` и `perimeter` — значения из замеров.
- `floor`: `wood`, `tile` или `deck` (балкон).
- `wall`: толщина наружных стен. Внутренняя стена — это просто зазор между помещениями.
- `type`: `window`, `door`, `balcony` или `entrance`.
- `axis`, `line`, `from`, `to`: проём идёт вдоль оси `axis` от `from` до `to` по грани стены `line`.
- `side` (1 или −1) и `hinge` (0 или 1): куда открывается дверь и где петля. Необязательные `sill` и `top` — низ и верх проёма.

## Устройство

Вся модель — один файл `index.html`. В `lib/` лежат three.js r147 (MIT) и pdf.js 3.11 (Apache-2.0), чтобы сайт не зависел от CDN. Планировки и обстановка хранятся в браузере (localStorage).
